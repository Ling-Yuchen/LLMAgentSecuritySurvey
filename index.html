Label Definitions And Rules

Lifecycle labels used in the survey
Input
Inbound context and observations.
Planning
Task decomposition, reasoning, and trajectory generation.
Decision
Commitment to the next action or delegation target.
Tool Execution
Execution through tools or the environment.
Memory
Transient or persistent state and its reuse.
Output
Externally visible results and side effects.
Monitoring
Observation and checking of agent behavior.
Inter-agent Comms
Information exchanged between agents.
Coordination
Organization of joint agent activity.
